# iZZi Financio

Telegram MiniApp: симулятор торговли криптофьючерсами с RPG-прогрессией трейдера.

Игрок начинает с $1 000 виртуальных денег и торгует бессрочными фьючерсами по **реальным ценам рынка в реальном времени**: открывает лонг и шорт, выбирает маржу и плечо (5x–150x), следит за ликвидацией и funding. Поверх торговли идёт карьера: уровни, навыки, экипировка, квесты, рейтинги и турниры. Все деньги в игре виртуальные, вывода нет.

Полный план игры: [План игры: Симулятор трейдера](https://claude.ai/artifact/1dhcPTni7q5s2SoeDmVfus).

## Как устроено

```
apps/
  web/       MiniApp: React + Vite + TypeScript, графики TradingView Lightweight Charts
  server/    API и WebSocket: Fastify, поток цен, свечи, проверка Telegram initData
  bot/       Telegram-бот на grammY: /start и кнопка меню открывают MiniApp
packages/
  shared/    Общий код: монеты, таймфреймы, формулы торговли (PnL, ликвидация, комиссии, funding)
```

**Цены.** Сервер держит одно WebSocket-соединение с Binance USDT-M Futures (потоки `aggTrade` и `markPrice@1s`) и раздаёт данные всем игрокам через свой WebSocket. Клиенты к бирже напрямую не ходят, поэтому все видят одну цену и лимиты биржи не тратятся.

**Свечи.** Таймфреймы от 1 минуты сервер берёт из REST `klines` Binance. Секундные таймфреймы (5с, 10с, 15с, 30с) Binance Futures не отдаёт, поэтому сервер собирает их сам из потока сделок и держит последние 6 часов в памяти. После перезапуска сервера секундная история копится заново.

**Устаревшие цены.** Если от биржи 10 секунд нет данных, сервер помечает цены как устаревшие, MiniApp показывает предупреждение и блокирует кнопки сделок.

**Монеты:** BTC, ETH (с 1 уровня), SOL, BNB, XRP, DOGE, TON, LINK (с 5 уровня).

**Плечо:** от 5x до 150x с шагом 1x. Уровни 1–9 — до 50x, 10–19 — до 100x, с 20-го — до 150x. Поддерживающая маржа 0,5%, для плеча выше 100x — 0,3%.

## Быстрый старт

Нужны Node.js 22+ и pnpm 10 (`corepack enable`).

```bash
pnpm install
cp .env.example .env
```

Для локальной разработки без Telegram и без доступа к Binance поставьте в `.env`:

```
PRICE_FEED=mock
DEV_AUTH_BYPASS=true
```

`mock` — случайное блуждание цены вместо биржи, `DEV_AUTH_BYPASS` пускает в API без подписи Telegram под тестовым игроком.

```bash
pnpm dev:server   # API и WebSocket на http://localhost:8080
pnpm dev:web      # MiniApp на http://localhost:5173
```

Проверки:

```bash
pnpm typecheck
pnpm test
pnpm build
```

## Переменные окружения

| Переменная | Где | Назначение |
| --- | --- | --- |
| `BOT_TOKEN` | server, bot | Токен бота из BotFather. Сервер проверяет им подпись initData |
| `PRICE_FEED` | server | `binance` (по умолчанию) или `mock` |
| `CORS_ORIGINS` | server | Адреса MiniApp через запятую |
| `DEV_AUTH_BYPASS` | server | Вход без Telegram для разработки. В production запрещён |
| `BINANCE_WS_URL`, `BINANCE_REST_URL` | server | Переопределить адреса Binance (необязательно) |
| `PORT` | server | Порт API, по умолчанию 8080 |
| `DOMAIN` | deploy | Домен MiniApp, для него Caddy получает сертификат |
| `VITE_API_URL` | web | Адрес API. Пусто в проде (тот же домен), локально `http://localhost:8080` |
| `WEBAPP_URL` | bot | HTTPS-адрес опубликованного MiniApp |
| `DATABASE_URL`, `REDIS_URL` | server | Понадобятся с этапа 2 |

## Деплой

Всё поднимается на одном сервере командой `docker compose --profile bot up -d --build`: Caddy раздаёт MiniApp и сам получает HTTPS, API и бот работают рядом. Пошаговая инструкция: [docs/DEPLOY.md](docs/DEPLOY.md).

## API

| Метод | Путь | Описание |
| --- | --- | --- |
| GET | `/api/health` | Состояние сервера и источника цен |
| GET | `/api/coins` | Монеты и таймфреймы |
| GET | `/api/tickers` | Последняя цена, mark price и funding по всем монетам |
| GET | `/api/candles?symbol=BTCUSDT&tf=10s&limit=500` | История свечей |
| GET | `/api/me` | Профиль игрока, нужен заголовок `Authorization: tma <initData>` |
| WS | `/ws` | Тикеры раз в секунду всем клиентам; свечи по подписке `{"type":"subscribe","symbol":"BTCUSDT","tf":"10s"}` |
